# 小说处理中心 1.0.32

- 修复 Edge 服务连接兼容性，升级到固定的 edge-tts 7.3.1；晓伊、晓晓默认随机，同一本书重试时保持同一音色。遇到服务限流时按冷却策略保留任务。
- 新增完整本地 LuxTTS，随包包含模型、嵌入式 Python、CPU/GPU 运行环境。解压后无需选择破甲目录；支持 Edge 优先、本地备用或仅本地三种模式。
- LuxTTS 默认随机使用晓伊、晓晓参考音色，支持 0.5～2 倍语速、MP3/WAV 私人声音导入和试听。参考音色听感可能与原生 Edge 不同。
- 移除阿里云配音界面与调用；百炼 AI 改写保留。已有配置、私人音色、队列、处理中目录、回执、日志和原文保留。
- 保留同名只跳过该书、其他书继续，以及同名成品超过 24 小时回收后再处理的逻辑。

Windows x64 完整包自带模型，约 5 GB；请完整解压至可写的本地 NTFS 文件夹，保留根 `Start-App.cmd` 和 `app/`，运行目录留空自动使用 `app/lux-runtime`。GPU 仍依赖电脑已有的兼容 NVIDIA 驱动，CPU 后备运行环境随包提供。首次模型加载需要等待。

完整包和旧客户端更新包均从本产品既有 OSS 目录分发，下载地址与 SHA-256 见 Release 附件。GitHub 单个附件的大小限制使完整模型包通过 OSS 直链提供，不将应用基础包标为完整包。GitHub Latest 继续保留 v1.0.18，保护历史客户端固定入口。

旧更新器保持原固定二进制。为兼容其 JSON 大小上限，客户端 `files` 包含应用与关键模型、完整载荷清单的哈希；全量清单另随包分发。更新 ZIP 的 SHA-256 覆盖全部模型和依赖。兼容旧 `requiredFiles` 的历史证书路径仅放置真实证书副本，不恢复阿里云配音 SDK。

本机短句实测中，Edge 与 LuxTTS 的晓伊、晓晓均生成非静音 MP3 并解码通过，Edge 两次请求均 HTTP 101；此前完整小说合成记录见本地功能交接。整篇逐字漏读、其他电脑硬件和现场表现不在本次已通过结论中。正式候选还须完成隔离升级、公开下载和更新清单回读核验后才切换生产。
