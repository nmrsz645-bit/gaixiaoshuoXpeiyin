# 小说处理中心 1.0.34

自动处理按「指定违禁词」词表在本地精确替换，保留全文、章节和换行。旧版百炼、DeepSeek 及场景审改配置保留，处理任务和接口自检均使用本地方式。需要明确替换的词使用 `原词=替换词`。

沿用原窗口、按钮、企业微信交付和配音流程。原来「AI 改写记录」入口继续打开每日 TXT，新条目标注本地替换的原词、改后词和次数。

切换时先核对旧发送回执。已确认发送的稿件按原样续办配音，待发送稿件从原文按本地词表处理。遇到损坏或缺失的回执时保留任务等待核对。

Windows 客户端沿用静默检查、安装和重启。更新包及完整包均含 LuxTTS 环境，完整包下载见[版本专属 Release](https://github.com/nmrsz645-bit/gaixiaoshuoXpeiyin/releases/tag/v1.0.34)。
