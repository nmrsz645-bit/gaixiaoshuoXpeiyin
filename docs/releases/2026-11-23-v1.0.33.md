# 小说处理中心 1.0.33

- “自动流程”页新增“AI 改写记录”按钮。每日一份 TXT，按原书名列出改稿采用的原文和改后文字。
- 改写交付成功后，按改稿完成日期保存到 `app/改写/AI改写记录/YYYY-MM-DD.txt`。普通改写和场景审改均收录。章节清理、截字和固定词替换另外执行。
- 同一天两本书同时完成会写入同一份报告。重试时沿用已保存的对照。尚未保存过对照的旧任务不会补录。
- 配音沿用 1.0.32 的 Edge、本地 LuxTTS 及配音设置。完整包和自动更新包都随包提供模型，下载约 4.9 GB。

运行验证用隔离目录和模拟小说。AI 改写协议、企业微信发送处理、队列和配音回执通过离线回归；真实服务和发布通道的分项记录随发布归档。

完整包下载及 SHA-256 见 [版本专属 Release](https://github.com/nmrsz645-bit/gaixiaoshuoXpeiyin/releases/tag/v1.0.33)。升级流程见 [发布指南](../RELEASE-GUIDE.md)。GitHub Latest 保持旧版兼容入口 v1.0.18。
