# LuxTTS 调速与声音克隆测试记录

2026-11-18，北京时间。本地分支 `codex/lux-voice-20261118`，候选版本 `1.0.32-lux-test.1`。基于此前 Edge 修复提交 `0385c78fcd9d2b78c78d9651b5d63901f86caae6`。

## 本次功能

配音引擎提供 `edge`、`lux_tts` 和 `edge_then_lux`。阿里云配音界面、SDK 调用和对应依赖已移除。阿里云百炼的 AI 请求功能继续可用。旧的阿里云配音引擎选项迁移为 Edge，其他旧配置字段保持存储。

LuxTTS 默认从晓伊、晓晓两种本地参考音色中随机选一次，同一本书各段沿用同一参考。两个内置参考来自相应 Edge 音色的五秒合成样音，随测试包分发。通过“LuxTTS 音色与声音克隆”可导入 MP3/WAV，保存私人参考音色并选择固定或随机配音。

私人音色保存在程序目录的 `lux-custom-voices`。音频转换只读取用户选择的文件，强制使用对应音频解封装格式及本地文件协议，取前五秒转为 24 kHz PCM16 WAV。原始音频保留。音色元数据与参考哈希一起原子发布。选择某个损坏音色时会明确报错。

LuxTTS 语速范围为 0.5～2.0 倍，默认 1.0。先完整合成本地 WAV，再用 FFmpeg atempo 调速并编码 MP3，采样率保持 48 kHz。每段完整生成后按顺序合并，MP3 解码通过后才进入原有成品事务流程。

“试听 LuxTTS”使用当前界面语速和已保存的本地音色，生成新 MP3 到“试听”目录并打开默认播放器。Edge 测试和本地试听各自只调用相应的语音引擎。开始业务前会先核对本地引擎、语速和参考音色，失败时尚未恢复或领取任务。

## 本地模型依赖

本候选读取破甲独立版完整包中的 `runtime/lux-tts`、`runtime/game-ocr/py312/python.exe` 和 `app/voice/lux_worker.py`（或根目录的 `voice/lux_worker.py`）。在设置里选择完整包解压根目录。

模型通过本机子进程运行，原破甲程序和引擎源码保持原状。GPU 失败时适配器可以尝试 CPU。模型与 CUDA 运行库由既有完整包提供，本次约 50 MB 的应用测试包只包含小说程序和两个内置参考样音。

## 验证结果

- 458 项离线回归通过，包含原有同名跳过、超过 24 小时回收、发送和配音事务测试。新检查覆盖旧配置保留、三种引擎、Lux 默认名单、私人音色选择、导入失败清理、损坏音色配置保留、禁止覆盖已有音频、试听播放条件、启动预检、失败多轮后的原文保留和测试版禁止更新器检查。
- 同一份真实 24.288 秒 LuxTTS 音频在 0.75、1.0、1.25 倍速时，MP3 解码时长分别为 32.379、24.281、19.446 秒，均完整解码通过。
- 在隔离目录真实导入一个测试克隆音色，原始参考哈希保持不变。通过 `voice_monitor.process_file`，使用这个私人配置、1.25 倍速和 RTX 5060 Ti 8 GB，完整生成 6746 字符的原创测试短篇。
- 该实际流程耗时 135.93 秒，输出 14,696,396 字节的 MP3，时长约 20 分 25 秒，解码通过。TXT 成功保留到测试成品目录，成功回调为 `lux_tts`，参考音频未变化。
- 本次新流程的全文逐段 ASR 捕获未完成，因此没有追加“新克隆音色整篇无漏读”的结论。此前短文和完整小说评估可参阅独立测试报告。
- 最终冻结包的主入口及五个相关模块与本次源码编译结果逐一一致；两个参考 WAV 哈希相同，未打入 `aliyun_tts` 或 `nls`。在空白 `app` 目录启动后，窗口版本为 `1.0.32-lux-test.1`，首次配置为两位默认参考随机。缺少 AI Key 的提示关闭后主窗口正常保留，超过首次更新延迟后 EXE 哈希未变化且未建立更新器目录。桌面截图此前两次捕获超时，本轮未能视觉验收设置页排版，不能据此宣称界面布局已验证。

## 当前范围与后续复验

程序候选在独立目录构建，未替换现有安装，未向 GitHub、OSS 或下载站发布。真实业务队列、日志、回执和原文保持原位。用户的私人克隆音色加入了 Git 忽略规则。

首次空白桌面验证时，目录名为 `app` 触发了旧更新器，将该隔离副本换回 1.0.31。隔离目录及记录保留。已在启动检查中增加版本后缀判断：带 `-` 的测试版本在安装或启动更新器前直接跳过；正式版启动路径仍有回归覆盖。交付测试包另外使用 `test-app` 目录。

故障电脑需选择本机可用的破甲模型目录再验证本地试听和三种语音模式。本机已验证 GPU 实际合成，CPU 回退仅有模拟检查。声音复刻的听感以试听为准。
